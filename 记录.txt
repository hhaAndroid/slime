slime 安装 megatron 时候采用的方式是 pip install -e ., 因为 megatron pyproject.toml 内部只能按照 core 模块。其余模块都是不会安装的。
因为在训练时候还会指定 pythonpath。虽然运行没有问题，但是在 vscode 里面，因为 pyproject 用了 pep517 协议导致 pylance 不认识，也就是无法跳转。

最简单解决办法是：不再采用 -e 安装，而是直接安装，这样也只能安装 core 模块，有部分模块还是无法跳转。因此最终解决办法是
修改  megatron pyproject.toml：

[tool.setuptools.packages.find]
include = ["megatron.core", "megatron.core.*", "megatron.training", "megatron.training.*", "megatron.legacy", "megatron.legacy.*","megatron.post_training", "megatron.post_training.*","megatron.rl", "megatron.rl.*"]

然后安装时候就全部会安装。这样跳转功能就正常了，也不用指定 pythonpath。
